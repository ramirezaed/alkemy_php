# Tienda PHP - Mini proyecto MVC manual (sin framework)

Proyecto de practica que modela una tienda simple (Productos, Categorias,
Usuarios y Carrito) usando **PHP puro**, **Programacion Orientada a Objetos**
y una arquitectura **MVC hecha a mano**, sin Laravel y sin base de datos
(los datos viven en un array en memoria)

Instalación del entorno de desarrollo

1. Instalar PHP
   En Windows: XAMPP - Descargar de apachefriends.org

2. Instalar Composer
   getcomposer.org/Composer-Setup.exe
